#### Context ###
We are building a rapid application to test the idea in the open market if the potential customers like and buy this. If the idea seems viable and working, we then refine and invest further to make it fully advanced. Until then test the core idea with minimal features and speed to launch application is expected with minimal efforts.

####Business Case####
The application is similar to www.autotrader.co.uk. The bank team is building similar application and given the requirements and we need to build the application with minimal efforts while not spening much on perfection, as long as the core idea works.

###Core challenges observed###
1. Inventory lacks accuracy, wrong inventory impacting customer churn.
2. Personalized recommendations, not generic but ultra personalized recommendation is important.
3. Finance options, should be simple and close to realistic that matches their circumustances, and have option to tweek the finance options.
4. Over all customer experience matters.
